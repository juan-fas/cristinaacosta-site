# cristinaacosta.ca

Website of the Cristina Acosta Mortgage Team (Enrich Mortgage Group, Mortgage Alliance), Calgary.

- Framework: Astro, static output. Hosting: Netlify. Forms: Netlify Forms.
- `npm run dev` to work locally, `npm run build` to produce `dist/`.
- Business facts (names, licences, links, calculator constants) live in `src/data/site.ts`. Change them there only.
- Fonts: Giga Sans (licensed) in `public/fonts`, Roboto via `@fontsource/roboto`.
- Photos: originals in Dropbox; the ones used live in `src/assets/photos` and are resized at build time.
